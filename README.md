## 🧑‍💻 About

This is the **v2.0** of Md. Jasim's personal developer portfolio — a full-stack developer and instructor. The portfolio is designed with a sleek **dark teal/cyan aesthetic** to reflect a professional yet creative identity. It highlights technical expertise, work experience, featured projects, articles, GitHub contributions, and more.

> *"I'm a passionate Full Stack Developer focused on building efficient, scalable and engaging digital experiences."*

---

## ✨ Features

- 🌑 **Dark-themed UI** with teal/cyan accent colors for a modern developer aesthetic
- 📱 **Fully Responsive** — optimized for mobile, tablet, and desktop
- ⚡ **Smooth Animations** — subtle transitions and hover effects throughout
- 🗂️ **Multi-Section Layout** — organized content from skills to contact
- 📊 **Stats Counters** — animated achievement numbers (students, projects, experience)
- 🏷️ **Technology Tags** — visual skill badges with categorization
- 🖼️ **Featured Project Cards** — with tech stack and live/repo links
- 📰 **Articles & Blog** — integrated latest articles section with category filters
- 🟩 **GitHub Contribution Graph** — real-time contribution heatmap display
- 📬 **Contact Form** — clean contact section with social links

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or above recommended)
- [Git](https://git-scm.com/)
- A modern web browser

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/ismailjosim/portfolio-v2.0.git

# 2. Navigate into the project directory
cd portfolio-v2.0

# 3. Install dependencies (if applicable)
npm install

# 4. Start the development server
npm start
```

### Or open directly

If this is a static HTML/CSS/JS project, simply open `index.html` in your browser:

```bash
open index.html
# or
start index.html  # Windows
```
